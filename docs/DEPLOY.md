# คู่มือติดตั้ง KPP Agri Data Center (ทำครั้งเดียว ~15 นาที)

ระบบมี 2 ส่วน
- **หน้าเว็บ** (GitHub Pages): `index.html` (สาธารณะ) และ `admin.html` (ผู้ดูแล)
- **ระบบหลังบ้าน** (Google Apps Script): อ่าน/เขียน Google Sheet, ตรวจรหัสผ่าน, ส่งอีเมล, นับผู้เข้าชม

> ทำขั้นตอนที่ 1–4 ด้วยบัญชี **noonoy.cmu@gmail.com** (เจ้าของชีต)

## 1. สร้างโปรเจกต์ Apps Script

1. เปิด https://script.new (บัญชีเจ้าของชีต) ตั้งชื่อโปรเจกต์ `KPP Agri Data Center API`
2. วางเนื้อหาทั้งหมดของ **`apps-script/build/Code.gs`** แทนโค้ดใน `Code.gs` (เป็นไฟล์รวมของ `apps-script/*.gs` ทั้ง 9 ไฟล์)
3. **การตั้งค่าโปรเจกต์ (⚙️)** → ติ๊ก "แสดงไฟล์ Manifest appsscript.json" → วางเนื้อหาจาก `apps-script/appsscript.json` → บันทึก

## 2. Script Properties (ไม่บังคับ)

| Property | ค่า |
|---|---|
| `SITE_URL` | ค่าเริ่มต้นคือ `https://krit-pj.github.io/KPP-Agri-Data-Center/` |
| `SUPER_ADMIN_USERNAME` | ค่าเริ่มต้นคือ `krit` |
| `NOTIFY_EMAIL` | อีเมลรับแจ้งเตือนคำขอใหม่ (ค่าเริ่มต้น = อีเมลเจ้าของสคริปต์) |
| `ADMIN_PREAPPROVED_PHONES` | เบอร์ Admin ที่อนุมัติล่วงหน้า คั่นด้วย `,` (ส่งแบบฟอร์มขอสิทธิ์แล้วใช้งานได้ทันที) |

**ไม่ต้องใส่รหัสผ่านใน Script Properties** — ดูข้อ 3

## 3. ติดตั้งอัตโนมัติ + ตั้งรหัสผ่าน Super Admin

ครั้งแรกที่ Web App ถูกเรียก (เปิดหน้าเว็บ) ระบบจะรัน `setupSystem()` ให้เอง: สร้างชีตระบบ, แปลงตัวเลขในชีต data,
สร้างชีตมุมมองรายพืช 9 ชีต และ **ส่งอีเมล "ตั้งรหัสผ่าน Super Admin" ไปที่อีเมลเจ้าของสคริปต์**
เปิดลิงก์ในอีเมล (ใช้ได้ครั้งเดียว ภายใน 48 ชม.) แล้วตั้งรหัสผ่านเอง ไม่มีใครอื่นเห็นรหัสผ่าน

> ทางเลือก: ตั้ง `SUPER_ADMIN_PASSWORD` ใน Script Properties แล้ว Run `setupSystem` ระบบเก็บ hash แล้วลบค่าตัวจริงทิ้ง

## 4. Deploy เป็น Web App

**ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป** แล้วอนุญาตสิทธิ์ (Sheets, ส่งอีเมล)
- เรียกใช้ในฐานะ: **ฉัน**
- ผู้มีสิทธิ์เข้าถึง: **ทุกคน**

คัดลอก URL ที่ลงท้าย `/exec`
(อัปเดตโค้ดครั้งต่อไป: **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL จะคงเดิม)

## 5. ใส่ URL ในหน้าเว็บ

แก้ `assets/js/config.js` → `API_URL: 'https://script.google.com/macros/s/……/exec'` แล้ว commit ขึ้น GitHub

## 6. ปิดการแชร์ชีตแบบสาธารณะ (สำคัญ — PDPA)

ชีตตอนนี้มีข้อมูลส่วนบุคคลของผู้ขอดาวน์โหลด และ hash รหัสผ่านของผู้ดูแล
**แชร์ → การเข้าถึงทั่วไป → จำกัด** (หน้าเว็บอ่านข้อมูลผ่าน Apps Script แล้ว ไม่ต้องแชร์ชีต)

## 7. เพิ่ม Admin

Admin เข้าระบบด้วย **เบอร์โทรศัพท์ + รหัสผ่าน** ที่ตั้งเองในแบบฟอร์ม `admin.html#request-admin` แล้วรอ Super Admin อนุมัติในแท็บ "คำขอสิทธิ์ Admin" (เบอร์ใน `ADMIN_PREAPPROVED_PHONES` ใช้งานได้ทันที)
หรือ Super Admin เพิ่มเองที่แท็บ **ผู้ดูแลระบบ**:

เข้า `admin.html` ด้วย `krit` → แท็บ **ผู้ดูแลระบบ** → เพิ่ม
- ชื่อผู้ใช้ = เบอร์โทรศัพท์ของ Admin 10 หลัก · บทบาท Admin · ตั้งรหัสผ่านเริ่มต้น แล้วแจ้งผู้ใช้ทางช่องทางที่ปลอดภัย
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ที่แท็บ **บัญชีของฉัน**

## 8. ตรวจสอบ

- เปิดหน้าเว็บ แผงชั้นข้อมูลต้องขึ้น 🟢 "Google Sheets ผ่านระบบหลังบ้าน"
- แท็บ **ระบบเชื่อมโยง** ตัวนับต้องเพิ่มเมื่อเปิดเว็บใหม่
- ลองส่งคำขอดาวน์โหลด → อนุมัติใน admin → ต้องได้อีเมลพร้อมลิงก์
- ใน Apps Script รัน `selfTest()` เพื่อดูจำนวนแถว/พืช/ลิงก์
