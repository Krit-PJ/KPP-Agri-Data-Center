# คู่มือติดตั้ง KPP Agri Data Center (ทำครั้งเดียว ~15 นาที)

ระบบมี 2 ส่วน
- **หน้าเว็บ** (GitHub Pages): `index.html` (สาธารณะ) และ `admin.html` (ผู้ดูแล)
- **ระบบหลังบ้าน** (Google Apps Script): อ่าน/เขียน Google Sheet, ตรวจรหัสผ่าน, ส่งอีเมล, นับผู้เข้าชม

> ทำขั้นตอนที่ 1–4 ด้วยบัญชี **noonoy.cmu@gmail.com** (เจ้าของชีต)

## 1. สร้างโปรเจกต์ Apps Script

1. เปิดชีต **KPP Agri Database (กำแพงเพชร)** → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดตัวอย่างใน `Code.gs` แล้วสร้างไฟล์ตามชื่อในโฟลเดอร์ `apps-script/` ให้ครบ 9 ไฟล์
   (`Config.gs`, `Api.gs`, `Data.gs`, `Auth.gs`, `Import.gs`, `Requests.gs`, `Counter.gs`, `Links.gs`, `Setup.gs`) คัดลอกเนื้อหาไปวางทีละไฟล์
3. **การตั้งค่าโปรเจกต์ (⚙️)** → ติ๊ก "แสดงไฟล์ Manifest appsscript.json" → วางเนื้อหาจาก `apps-script/appsscript.json`

## 2. ตั้งค่า Script Properties

**การตั้งค่าโปรเจกต์ → Script Properties → เพิ่ม**

| Property | ค่า |
|---|---|
| `SUPER_ADMIN_USERNAME` | `krit` |
| `SUPER_ADMIN_PASSWORD` | รหัสผ่าน Super Admin (อย่างน้อย 8 ตัว) — ระบบจะเก็บเป็น hash แล้ว **ลบค่านี้ทิ้งเอง** |
| `SITE_URL` | `https://krit-pj.github.io/KPP-Agri-Data-Center/` |
| `NOTIFY_EMAIL` | (ไม่บังคับ) อีเมลรับแจ้งเตือนคำขอดาวน์โหลดใหม่ ไม่ใส่ = อีเมลเจ้าของสคริปต์ |

ชื่อผู้ใช้ไม่สนตัวพิมพ์ใหญ่/เล็ก (`Krit` = `krit`)

## 3. รัน setupSystem()

เลือกฟังก์ชัน `setupSystem` → **เรียกใช้** → อนุญาตสิทธิ์ (Sheets, ส่งอีเมล) → ดู Execution log ควรเห็น
```
PASS: ชีตระบบพร้อม
PASS: แปลงค่าตัวเลขในชีต data … เซลล์
PASS: ชีตมุมมองรายพืช 9 ชีต
PASS: Super Admin "krit" พร้อมใช้งาน (ลบ SUPER_ADMIN_PASSWORD ออกจาก Script Properties แล้ว)
```
รันซ้ำได้ทุกเมื่อ (เช่น หลังอัปเดตโค้ด) ไม่ทำข้อมูลเสีย

## 4. Deploy เป็น Web App

**ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
- เรียกใช้ในฐานะ: **ฉัน**
- ผู้มีสิทธิ์เข้าถึง: **ทุกคน**

คัดลอก URL ที่ลงท้าย `/exec`
(อัปเดตโค้ดครั้งต่อไป: **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL จะคงเดิม)

## 5. ใส่ URL ในหน้าเว็บ

แก้ `assets/js/config.js` → `API_URL: 'https://script.google.com/macros/s/……/exec'` แล้ว commit ขึ้น GitHub

## 6. ปิดการแชร์ชีตแบบสาธารณะ (สำคัญ — PDPA)

ชีตตอนนี้มีข้อมูลส่วนบุคคลของผู้ขอดาวน์โหลด และ hash รหัสผ่านของผู้ดูแล
**แชร์ → การเข้าถึงทั่วไป → จำกัด** (หน้าเว็บอ่านข้อมูลผ่าน Apps Script แล้ว ไม่ต้องแชร์ชีต)

## 7. เพิ่ม Admin

เข้า `admin.html` ด้วย `krit` → แท็บ **ผู้ดูแลระบบ** → เพิ่ม
- ชื่อผู้ใช้ = เบอร์โทรศัพท์ของ Admin 10 หลัก · บทบาท Admin · ตั้งรหัสผ่านเริ่มต้น แล้วแจ้งผู้ใช้ทางช่องทางที่ปลอดภัย
- ผู้ใช้เปลี่ยนรหัสผ่านเองได้ที่แท็บ **บัญชีของฉัน**

## 8. ตรวจสอบ

- เปิดหน้าเว็บ แผงชั้นข้อมูลต้องขึ้น 🟢 "Google Sheets ผ่านระบบหลังบ้าน"
- แท็บ **ระบบเชื่อมโยง** ตัวนับต้องเพิ่มเมื่อเปิดเว็บใหม่
- ลองส่งคำขอดาวน์โหลด → อนุมัติใน admin → ต้องได้อีเมลพร้อมลิงก์
- ใน Apps Script รัน `selfTest()` เพื่อดูจำนวนแถว/พืช/ลิงก์
