# KPP Agri Data Center · ศูนย์ข้อมูลการเกษตรจังหวัดกำแพงเพชร

แผนที่และแดชบอร์ดข้อมูลการเพาะปลูกพืชเศรษฐกิจ 9 ชนิด รายอำเภอ (11 อำเภอ) ปี 2556–2567
หน้าเว็บอยู่บน **GitHub Pages** และฐานข้อมูลอยู่ใน **Google Sheets** ผ่าน **Google Apps Script**

| หน้า | ใช้ทำอะไร |
|---|---|
| `#map` Smart Map | แผนที่ระบายสีรายอำเภอ เลือกพืช/ปี/ตัวชี้วัด แตะอำเภอเพื่อดูรายละเอียดและแนวโน้ม |
| `#dashboard` แดชบอร์ด | โครงเดียวกับรายงาน Power BI: KPI 4 ตัว, เลือกหลายปี, กราฟรายอำเภอ, สัดส่วนพืช, ตารางเปลี่ยนแปลงรายปี |
| `#soil` ศดปช. | ศูนย์จัดการดินปุ๋ยชุมชน: KPI, กราฟรายอำเภอ, ปีเริ่มดำเนินการ, ตารางค้นหา และชั้นข้อมูลจุดบนแผนที่ (`#map?soil=1`) |
| `#request` ขอข้อมูล | แบบฟอร์มขอดาวน์โหลด (ชื่อ-สกุล ตำแหน่ง หน่วยงาน วัตถุประสงค์) → Admin อนุมัติ → ลิงก์ทางอีเมล |
| `#links` ระบบเชื่อมโยง | ลิงก์ไปยังระบบอื่น (Super Admin จัดการได้) + สถิติการเข้าใช้งาน |
| `admin.html` | Super Admin / Admin: นำเข้าข้อมูล, อนุมัติคำขอ, จัดการ ศดปช. ลิงก์ และผู้ดูแล · `admin.html#request-admin` แบบฟอร์มขอสิทธิ์ Admin |

เลือกพืชจากแถบไอคอนด้านบน แล้วทั้งแผนที่ แดชบอร์ด และ URL จะเปลี่ยนตาม (แชร์ลิงก์ได้ เช่น `#dashboard?crop=อ้อย&years=2565,2566`)

## ติดตั้ง

ดู **[docs/DEPLOY.md](docs/DEPLOY.md)** (ติดตั้ง Apps Script, ตั้ง Super Admin, Deploy, ใส่ `API_URL`)
ก่อนตั้ง `API_URL` หน้าเว็บจะแสดงข้อมูลจากไฟล์สำรองใน `data/` ได้ แต่ระบบขอข้อมูล ตัวนับ และ Admin ยังใช้ไม่ได้

## โครงสร้าง

```
index.html                 หน้าเว็บสาธารณะ
admin.html                 หน้าผู้ดูแล
assets/js/config.js        ตั้งค่า API_URL, โลโก้, ลำดับพืช
assets/js/api.js           เรียก Apps Script
assets/js/data.js          โหลดข้อมูล + measures (แปลงจาก DAX)
assets/js/icons.js         ไอคอนพืช SVG
assets/js/map.js           Leaflet choropleth
assets/js/dashboard.js     Chart.js (มือถือเปลี่ยนเป็นกราฟแท่งแนวนอน)
assets/js/request.js       ฟอร์มขอข้อมูล + หน้ารับไฟล์ (?dl=)
assets/js/app.js           state กลาง, routing, แถบพืช, ลิงก์, ตัวนับ
assets/js/admin/importer.js  อ่าน CSV/Excel/PDF → จับหัวตาราง อำเภอ พืช ปี
assets/js/admin/admin.js     หน้าผู้ดูแล
apps-script/*.gs           ระบบหลังบ้าน (วางใน Apps Script)
data/                      ไฟล์สำรอง + ขอบเขตอำเภอ
docs/                      DEPLOY, SHEET_SCHEMA, DAX_to_JS
tests/                     ทดสอบ backend (จำลอง Apps Script) และตัวนำเข้า
```

## ทดสอบ / พัฒนาในเครื่อง

```bash
npm install
npm test                 # 21 ชุดทดสอบ: backend + importer + ศดปช.
npm run dev              # http://localhost:8790 พร้อม Apps Script จำลอง (ทดสอบในเครื่อง: krit / Dev#pass2026)
```

## หมายเหตุข้อมูล

- ชีต `data` คือแหล่งข้อมูลหลักแหล่งเดียว ชีต `พืช_…` เป็นมุมมองอ่านอย่างเดียว (QUERY) สร้างใหม่อัตโนมัติ
- ปีที่ทั้งจังหวัดเป็น 0 ทั้งหมดถือว่า "ยังไม่มีข้อมูล" และไม่แสดง
- ผลผลิตเฉลี่ย = ผลผลิตรวม ÷ เนื้อที่เก็บเกี่ยวรวม × 1,000 (กก./ไร่) · ยางพาราคิดต่อเนื้อที่กรีด
- ไฟล์ Excel ต้นฉบับมีชีตรายพืชที่ตัวเลขไม่ตรงกับชีตรวมบางปี (ดู `tests/fixtures/source-consistency.txt`) ระบบนำเข้าจะแสดงเป็น "แก้ไขค่าเดิม" ให้ตรวจก่อนยืนยันเสมอ
- ขอบเขตอำเภอ: OpenGISData-Thailand · โลโก้กรมส่งเสริมการเกษตร · ตราจังหวัด: Wikimedia Commons
